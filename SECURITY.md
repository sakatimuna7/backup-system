# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.12.x  | ✅ |
| 0.11.x  | ✅ |
| < 0.11  | ❌ |

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Please report privately via email: **hello@hamdanhabibi.my.id**

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Your suggested fix (optional)

**Response timeline:**
- Acknowledgement: within 48 hours
- Fix or workaround: within 7 days for critical issues

Fixes will be released as a patch version and credited in the changelog (unless you prefer to stay anonymous).
